# TaskFlow Manager

## Features
- User Registration
- User Login
- Create Tasks
- Update Task Status
- Delete Tasks
- Todo, In Progress and Done workflow

## Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript

## Setup Instructions

1. Clone the repository
2. Create a MySQL database named task_manager
3. Update application.properties with your database credentials
4. Run the Spring Boot application
5. Open register.html and start using the application

## Assumptions
- Single-user task management
- Status values are fixed

## Future Improvements
- JWT Authentication
